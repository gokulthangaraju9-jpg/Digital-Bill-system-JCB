# Digital Bill System JCB
Smart & Instant Billing, Booking, and Machine Management Platform for Earthmovers and JCB Fleet Businesses.

## Features
- **Digital Billing & Calculator**: Instant hourly calculation, operator beta, advance deduction, printable thermal receipts, image & PDF exports.
- **Machine Fleet Management**: Real-time status tracking (Available, In Service, Maintenance).
- **Online Booking System**: Real-time booking submissions with backend synchronization.
- **Interactive Gallery & Services**: Showcase machines, attachments, and past earthmoving operations.
- **Admin Dashboard**: Overview of revenue, fleet stats, customer inquiries, and booking approvals.
- **REST API Backend**: Express & Redis with automated fallback store.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/gokulthangaraju9-jpg/Digital-Bill-system-JCB.git

# Install dependencies
npm run install-all
```

### Running Locally
```bash
# Start backend server
npm run server

# Start frontend application (in another terminal or concurrently)
npm run dev
```

The frontend will run at `http://localhost:5173` and backend at `http://localhost:5000`.

## Deployment
Configured for seamless deployment on Vercel (frontend) and Render/Railway (backend).
